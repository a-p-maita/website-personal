# website-personal

Personal website and/or portfolio to show off skillset in deploying and managing it.

---

## Architectural Decision Record (ADR)

I opted to utilise an `ADR.md` ([ADR](https://github.com/adr/madr/tree/develop)) to show justified software design choices made for this project which are significant and/or matter.

In a nutshell, this allows me to show that I have put thought into which technologies to use, and what rationale lead me to each and every step.

It gives good insight into my level of understanding as well as the opportunity for reviewers to guide me into bettering my implementation.
